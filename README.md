# 🃏 Pokémon Memory Game 🎮

## 🎯 Goal
Create a **10-card memory game** where users try to match pairs of Pokémon cards.  
- Users can **flip two cards** at a time.  
- If the cards **match**, they stay flipped.  
- If they **don’t match**, they flip back over.  
- The game ends when **all cards are matched**.  

This version is themed with **Pokémon**, making it fun and visually engaging for fans!  

---

## 🚀 Features
- ✅ 10 Pokémon cards (5 matching pairs)  
- ✅ Click-to-flip functionality  
- ✅ Match detection and card persistence  
- ✅ Game ends when all cards are matched  
- ✅ Fun Pokémon visuals and animations  

---

## 🧩 Tech Stack
- **HTML** – Game board and cards structure  
- **CSS** – Card styling, flip animations, and layout  
- **JavaScript** – Game logic, card selection, match checking  

---

## 💻 How It Works
1. Cards are displayed face-down on a grid.  
2. The user clicks two cards to reveal them.  
3. JavaScript checks if the two cards **match**:  
   - ✅ If matched, cards stay flipped  
   - ❌ If not matched, cards flip back after a short delay  
4. Repeat until all pairs are matched.  
5. Display a **congratulations message** when the game is complete.
