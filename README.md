# Memory Game

This is a simple memory game implemented using HTML, CSS, and JavaScript. The game consists of 10 cards (5 pairs), and the player's goal is to find all the matching pairs.

## How to Play

1.  Open the `index.html` file in your web browser.
2.  Click on a card to flip it over and reveal its symbol.
3.  Click on another card to flip it over.
4.  If the two cards match (have the same symbol), they will stay flipped and turn green, indicating a match.
5.  If the two cards do not match, they will flip back over.
6.  Continue flipping cards until all pairs are matched.
7.  A "Congratulations! You won!" alert will appear when all pairs are found.

## Project Structure

The project is organized into three files:

* `index.html`: Contains the HTML structure of the game, including the game board and card elements.
* `style.css`: Contains the CSS styles for the game, including card appearance and layout.
* `script.js`: Contains the JavaScript logic for the game, including card shuffling, flipping, matching, and win detection.

## Technologies Used

* HTML: For the structure of the web page.
* CSS: For styling the game elements.
* JavaScript: For implementing the game logic and interactivity.

## How to Run

1.  Save the `index.html`, `style.css`, and `script.js` files in the same directory.
2.  Open the `index.html` file in your web browser.

## Features

* 10 cards (5 pairs) for a classic memory game experience.
* Random card shuffling to ensure a different game each time.
* Visual feedback for flipped and matched cards.
* Simple and intuitive user interface.
* Win detection and alert message.
