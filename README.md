# ♠️ Week08 Bootcamp2019a Project: Matching Card Game

### Goal: Make a 10 card memory game - users must be able to select two cards and check if they are a match. If they are a match, they stay flipped. If not, they flip back over. Game is done when all cards are matched and flipped over. 

Project Description:

Memory fruit card game App to created to test your memory. Match each pair of fruits to win. 

App uses HTML, CSS & Javascript. The JS code ivolves a blend of classList functions and randomization.

I am happy with this app. It is simple and it works.
