
# SneakerHead Matching Game

## Description
Make a 10 card memory game - users must be able to select two cards and check if they are a match. If they are a match, they stay flipped. If not, they flip back over. Game is done when all cards are matched and flipped over.

## Technologies
- HTML
- JavaScript
- Node.js
- API

## How It Works
1. User clicks two cards to flip over
2. If a pair matches it gets taken off the borad
3. If a pair doesn't match they flip back over 
4. Repeat until all 10 SneakerHead matching pairs are together.
