# Memory Card Game

A simple memory matching card game built with CSS, HTML, and JavaScript

## How it Works

Player clicks a card to reveal its images hidden underneath.
- Click 2 cards to reveal their image
- If the two images match, the cards stay flipped
-  Only 2 cards can be selected at a time
- The game continues until all matching pairs are found
