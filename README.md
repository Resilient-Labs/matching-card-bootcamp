The Matching Card Game is a web-based memory game where users are presented with 10 cards. Each card has a hidden letter, and there are five matching pairs. Users click two cards at a time to reveal their contents. If the two cards match, they stay flipped; if not, they flip back over. The game continues until all pairs are matched, and the player wins.

Find the live demo at https://ishelvirakeira.github.io/matching-card-bootcamp/

Tools used: HTML, CSS, JavaScript

I Learned how to:
- to respond to user clicks, control interactions with flags like lock to prevent multiple selections, and manage game logic.
- to check for matches, track flipped cards, and detect when the game is won. 
- to use arrays to store card values, flipped card IDs, and matched pairs
