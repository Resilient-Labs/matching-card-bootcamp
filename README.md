# ♠️ Week08 Bootcamp2019a Project: Matching Card Game

### Goal: Make a 10 card memory game - users must be able to select two cards and check if they are a match. If they are a match, they stay flipped. If not, they flip back over. Game is done when all cards are matched and flipped over. Example: http://www.fruit-burst.co.uk/fun-and-games/pairs-game

this project was really interesting. It was the first time where i felt like going back to refactor and make cleaner code made sense. Using if and else statements with this game creates a very complex and difficult to comprehend codebase, and there were lots of opportunities to organize code in a way that made for a much cleaner way of understanding. However, as a software engineer, our job is to assess risk and evaluate time allocation for a given task, leading me to conclude that it would be the most efficent to produce a working result fast, and then if time allows go back to refactor. This is a decision i think will be of paramount importance in the workplace. In the workplace, and for clients especially, all that matters is that the end result works and works well. Best practices come secondary to a working product. In the field, we are always looking for a product that works. So focusing first and foremost on a working end result is the best use of everyones time. That way, the team can go back and assess: Are we adding additional functionality? Will the way we wrote this code prove troublesome for future features we add down the line? Or is our application complete and additional funcitonality is not the goal now? What if we spent 4 times as long creating a product that has "cleaner code" but in the end, we could have saved time for more valuable tasks? Especially in the realm of freelancing, your time is your own and clients only want to see that you can push an app that meets expectations. They dont care if you javascript uses constructor functions or not. As engineers, its our most important job to determine wether a task demands our extremely prescious attention, or if we should prioritize other important things.
