# ✨ Project: Matching Card Game

### Goal: Make a 10 card memory game where users must be able to select two cards and check if they are a match. If they are a match, they stay flipped. If not, they flip back over. Game is done when all cards are matched and flipped over.

## Result: Cozy Card Memory Match

* 10 cards with 5 different cozy emojis
* Game Board is randomized upon page load
* Match count is updated when you get a match !
* Result of card flip is displayed upon second card reveal

# How to Use

1. Check out the [Cozy Card Memory Match](https://programmingkat.github.io/matching-cards/).
2. Flip two cards
3. If you get a match, your match count will go up by one
4. If you don't get a match, cards will flip back upside down
5. Game ends once all cards are matched!
